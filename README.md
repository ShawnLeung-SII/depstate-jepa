# DepState-JEPA

Project website for **DepState-JEPA: Learning Depth-Grounded State Representation for Visual Perception and Manipulation**.

**Website:** https://shawnleung-sii.github.io/depstate-jepa/

**Code:** Coming soon. This repository contains the project website, research figures, paper, and recorded demonstrations.

## Contents

- `index.html`: paper overview, authors, abstract, methodology, comparisons, demonstrations, ablations, and citation.
- `style.css`: responsive academic project-page design, aligned with the PRISM project website.
- `app.js`: spatial-result galleries, task/viewpoint/modality video selection, figure enlargement, and citation copying.
- `assets/`: paper PDF, paper figures, institutional branding, and web-optimized robot demonstrations.
- `citation.bib`: bibliographic record; update with the official venue/arXiv record when confirmed.

## Local preview

Open `index.html`, or run `python3 -m http.server 4174` in this directory.

## Publication

GitHub Pages serves the root directory of the `main` branch. All asset references are relative for project-site compatibility.

## Updating resources

Replace the disabled Code button with the official repository URL when implementation code is released. Add the confirmed publication venue and arXiv identifier to the page and citation when available.

Institutional marks are used to identify author affiliations. Shandong University mark source: https://www.sdu.edu.cn/images/logo.svg. Other marks are retained from the author’s PRISM project website.
