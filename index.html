Abstract

Predictive representations for robot manipulation should connect scene geometry with the state changes induced by actions. Our intuition is that understanding what an action will change starts with understanding where things are: complementary RGB and depth observations ground a common scene representation from which to infer those changes. Guided by this intuition, we introduce DepState-JEPA, a dual-stream RGB–Depth joint-embedding predictive architecture that connects spatial understanding with action-conditioned prediction through a shared latent state, DepState.

Built on V-JEPA 2.1, the framework uses depth both as a complementary observation stream and to ground both modalities in metric 3D space, aggregating shared information into DepState while retaining modality-private features for decoding. Ray-conditioned readouts predict local features without target depth; after an action-conditioned transition, the same decoders predict future RGB and depth features using the predicted state and fixed initial private features. Robot-state readouts provide recursive proprioceptive inputs; object-trajectory supervision and calibrated forward kinematics shape state learning through motion targets and joint–TCP consistency.

Comparisons show stronger RGB-encoder transfer after RGB-D adaptation, feature completion, conditioned visual forecasting, and manipulation success. Within-model ablations identify contributions from depth content, metric coordinates, and future-state matching, with additional control gains from FK regularization.

01 / COMPLEMENTARY OBSERVATIONS

Ground perception in 3D

Independent RGB and depth encoders capture appearance and geometry. Visible metric depth places both streams in a common 3D coordinate frame.

02 / A COMMON STATE INTERFACE

Share what should evolve

DepState aggregates shared information. Private features preserve modality-specific decoding detail and stay fixed throughout temporal rollout.

03 / ACTION-CONDITIONED DYNAMICS

Connect perception to action

Learned transitions evolve DepState under actions and proprioception. Unified readouts support feature prediction, robot-state prediction, and manipulation.

METHOD

One depth-grounded state. Spatial and temporal readouts.

Depth-grounded state construction

RGB and depth features are lifted using visible depth and camera intrinsics. Shared–private projections separate the aggregation pathway from modality-specific decoding pathways. Learned queries aggregate shared content into DepState.

Ray-conditioned feature prediction

Local features are queried by camera rays without using target depth. The same decoders support masked completion and future visual feature prediction, with the initial private memory fixed during temporal rollout.

Physically supervised dynamics

Action-conditioned transitions predict the next state. Robot-state heads supply recursive proprioception; object-trajectory supervision and calibrated forward kinematics provide motion targets and joint–TCP consistency during training.

STAGE A

RGB-D adaptation

Learn spatial and temporal representations from images and video through masked shared-feature completion and dense modality-feature prediction.

STAGE B

Robot post-training

Learn action-conditioned transitions and physical readouts, with future-state matching, feature targets, physical supervision, and RGB-D replay.

CONTROLLED ABLATIONS

What makes the shared state effective?

Within-model interventions isolate geometry, information sharing, and temporal supervision. L1 and cosine aggregate three prediction tasks; success rate aggregates 50 Meta-World tasks and two real-world tasks, following the paper’s ablation protocol.

Scope and future directions

Real-world evaluation uses calibrated fixed external cameras, embodiment-specific training, and matched indoor workspaces for drawer and cup manipulation. Moving cameras, zero-shot transfer across embodiments, broader workspace changes, and larger displacements with newly visible surfaces remain directions for further study.

The temporal comparisons measure forecasting conditioned on recorded actions and proprioception. Control rollouts instead use predicted proprioception. Feature accuracy alone does not establish precise physical trajectories or action sensitivity in moving regions.
